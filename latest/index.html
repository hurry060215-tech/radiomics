从影像与表格，走到可审查的研究结果#

RADIOMICS · 独立研究软件

Python 提供交互与绘图，原生核心支撑无 Python 的 CLI。明确选择每一步的后端，围绕输入、患者划分、参数与输出，完成影像组学和轻量病理分析；速度、峰值内存和数值误差分别验证。

跟着教程学，带着自己的文件做#

第一次使用，先完成安装检查与快速开始，再进入八篇可逐单元运行的教程。01–06 使用固定合成数据学习软件行为；07 使用单例公开 CT；08 使用真实 UCI 细胞核测量表。每条路线都说明输入、步骤、输出和替换为自己数据的方法。

已有研究文件时，从用户指南准备 cohort、临床表、patch manifest 或 embedding 行 ID。影像与临床路径保留患者分组；病理路径保留 patient→slide→tile 层级和真实坐标。程序不从文件名或特征值猜结局。

先确认支持范围，再解释结果#

原生能力覆盖明确的 Original 特征子集、三任务建模和普通图像病理工具；自动分割、深度模型训练、通用 WSI 解码和配准不在本轮范围。请查支持矩阵和验证说明。Python 原生示例显式指定 backend="rust"，CLI 调用同一计算核心。

合成分数只证明流程可运行。单例 CT 没有训练结局；UCI source ID 不能证明患者独立。患者模型概率也不能作为局部 tile 预测图。正确性、研究效能与性能分别报告，详见验证与开发。
