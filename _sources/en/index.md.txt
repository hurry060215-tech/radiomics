# Radiomics documentation

ov-radiomics is an independent research package with a Rust numerical core,
a Python interface and a separate command-line executable. It supports explicit
subsets of radiomics, clinical modeling and ordinary-image pathology workflows.
It does not establish clinical validity or replace study design and validation.

Start with [installation](installation.md), then run the
[quickstart](quickstart.md). The [tutorial directory](tutorials/index.md) explains
the inputs and limits of each route. Read the
[support matrix](../reference/support-matrix.md) before choosing a backend.

The maintained guides and notebook narratives are primarily in Simplified
Chinese. This English entry point covers installation, first execution,
navigation and ecosystem responsibilities; it does not claim a complete
translation of every reference page.
