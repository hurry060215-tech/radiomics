教程：按任务选择路线#

先完成安装，再从完整仓库启动 Jupyter。每篇 Notebook 都包含代码、中间检查、保存的实际输出和解释；按顺序执行单元，使用新的输出目录。网页构建只展示已保存输出，不自动下载数据或训练。

四条学习路线#

影像组学 · 01 → 04

从 ROI 到 Original 特征

NIfTI / mask → 几何与提取 → 多区域与时间点 → 特征和质量记录。

合成入门 建模与统计 · 02 → 03

从特征到可保存的模型

特征与结局 → 患者分组 → 分类／回归 → 评价、.rad 与外部预测。

合成入门 轻量病理 · 05 → 06

从 patch 到层级结果

普通图像 / embedding → QC、ID 对齐 → 聚合 → 真实 tile 分数覆盖图。

合成入门 真实数据 · 07 / 08

检查真实文件与数据来源

公开 CT 或细胞核测量表 → 许可与 SHA → 提取或固定记录留出 → 可追溯结果。
